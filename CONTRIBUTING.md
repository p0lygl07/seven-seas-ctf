# Contributing

Thanks for your interest in the 7 Seas CTF!

This repo is mainly **documentation and companion tooling** for a physical product sold by
P01yg107 Labs. Where the device runs upstream open-source firmware, that firmware is credited
in the README — firmware bugs or features belong upstream.

**Good contributions here:**
- Fixes or clarifications to the setup / usage docs
- Extra troubleshooting entries that helped you
- Additional harmless example recipes for learning
- Translations

**How:**
1. Fork the repo
2. Make your change on a branch
3. Open a pull request describing what you changed and why

Please keep everything consistent with the Responsible & Authorized Use policy in
[`docs/SAFETY.md`](docs/SAFETY.md). PRs that add real-world attack payloads aimed at
non-consenting targets will be closed.
