# 7 Seas CTF — Setup

## Setup (at launch)

> **Status: in the lab — coming soon.** This page is a placeholder so the badge has a home
> the day it ships. Details below will be finalized at launch.

### What you'll need
- A **7 Seas CTF** badge
- A hardware interface — the **Jolly BUS Pirate** is the intended tool (https://github.com/p0lygl07/jolly-bus-pirate)
- Jumper leads and a USB cable
- A serial terminal at **115200 baud** (or the Bit Pirate GUI)

### Getting started
1. Power the badge over USB.
2. Connect your interface to the UART header and open a serial console.
3. The badge greets you and points you toward the first flag.

Each flag unlocks a hint toward the next. No soldering required — everything is on
labelled headers.
