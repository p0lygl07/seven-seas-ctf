# 7 Seas CTF — Usage

## The five flags

| # | Interface | Goal |
|---|-----------|------|
| 1 | UART      | Find the serial console and listen in |
| 2 | I²C EEPROM| Dump the chip and read the log |
| 3 | SPI flash | Pull the image and search the hold |
| 4 | GPIO      | Work out the pin sequence |
| 5 | WiFi      | Board the badge's own web app |

Detailed walkthroughs, hints, and the flag format will be published here at launch. The
badge is meant to be worked top-to-bottom — each flag teaches the skill you need for the next.

> This is a self-contained practice target you own. Nothing here touches anyone else's gear.
